# Real-Time System Incident Dashboard

## Overview

This app demonstrates a basic real-time dashboard using:

- `React` for the frontend
- `Express` and `Node.js` for the backend
- `PostgreSQL` for data storage
- `WebSockets` for real-time updates

## Features

- Create incidents with a service, severity, description, and status.
- Receive new incidents and live dashboard updates over WebSockets without refreshing the page.
- View incident trends, severity summaries, and recent activity.
- Filter incident history by service and event type.
